02 / Change Review

ここは直す。ここは、守る。

修正してほしい範囲と、変えてほしくない範囲を画像に残す。
指示を渡したあとも、修正前後の違いを確認できます。

修正を伝える。
余計な変更を、見逃さない。

01画面を読み込む

PNG / JPEG / WebP

1枚10MB・1,600万画素まで。長辺2,000pxに縮小して処理します。比較には元の縦横サイズが同じ2枚を使ってください。

02範囲を囲んで、指示を残す

修正前の画像を、ドラッグまたは指で囲んでください。
0 / 60 範囲
＋
修正前の画像から、はじめよう。

右上の「サンプルを試す」でも体験できます。

オレンジ＝修正、青＝変更禁止、グレー＝比較から除外。表示範囲は数値でも指定できます。

数値で範囲を追加する（キーボード対応）

位置は修正前画像の左上が基準です。幅・高さを含めて100%を超える範囲は作れません。

03修正前後を比べる

比較前
修正前と修正後の画像を読み込むと、変更禁止範囲もまとめて比較できます。

修正指示

範囲を選択
画像を囲むと、ここに指示を書けます。「変更しない」範囲には、維持したい内容を記入してください。

指示を渡す・続きを保存する

プロジェクトJSONには画像・指示が含まれます。共有前に個人情報を確認してください。画像は端末に自動保存しません。

指示のプレビュー
変更禁止の指定は、AIや作業者を強制する機能ではありません。画像内の情報や意味は解析せず、色の違いを可視化します。
ここ直して / 1.0.0　API不要 · ログイン不要 · 外部送信なし
大切なデータは書き出して保管してください。

ここ直しての使い方

1. 修正前の画像を読み込み、「修正する」「変更しない」「比較から除外」のいずれかを選んで範囲を囲みます。数値での追加も可能です。

2. 範囲を選び、指示と合格条件を書きます。指示はMarkdown・コピー・注釈付きPNGで渡せます。

3. 同じ縦横サイズの修正後画像を読み込み、「差分をチェック」を押します。グレーの除外領域は比較しません。修正の合否は自分で確認します。

画像は白背景に合成し、長辺2,000px以内に縮小して比較します。透明度の違い・細かな文字・端末ごとの描画差で結果が変わる場合があります。画像の寸法が違う場合、自動で引き伸ばして比較はしません。

「プロジェクト保存」で画像を含むJSONを保存できます。再読み込み時は手動確認を解除します。このタブを閉じると、未保存の画像と指示は失われます。

ページの配信は公開元のサービスを利用しますが、入力内容・原稿・画像を送信する処理はありません。ブラウザ拡張機能や端末自体の安全性までは保証しません。
